# CountFlow — نظام الجرد المستقل

## التطبيقات المنشورة
- `Counter.html`: محطة مندوب الجرد (المسح، إدخال الكميات، العمل دون اتصال، مزامنة الطابور).
- `Counter-supervisor.html`: غرفة مراقبة الجرد (المشاريع، الأعضاء، الجلسات، الاستيراد، المواقع، البث المباشر والتقارير).

## البيئة
- Supabase project: `rawaea-staging`
- Project ref: `hfzznsiprnwkpayskzhu`
- لا توجد أي تبعية تشغيلية على مشروع SMART ERP.
- لا يوجد اتصال بجداول المخزون أو قيود المحاسبة. سجلات العدّ مرجعية مستقلة ولا ترحّل مخزوناً.

## التهيئة الأولى
1. أنشئ أول مستخدم مشرف من Supabase Dashboard → Authentication → Users (دعوة/إنشاء مستخدم بكلمة مرور قوية).
2. افتح `Counter-supervisor.html` وسجّل الدخول بهذا البريد وكلمة المرور.
3. أنشئ مشروع الجرد الأول؛ Trigger قاعدة البيانات ينشئ عضوية المشرف تلقائياً.
4. أضف المندوبين والمراجعين من تبويب فريق الجرد. الحسابات تُنشأ عبر Edge Function محمية تتحقق من JWT وعضوية المشرف.
5. أنشئ هيكل المتجر، استورد الأصناف، أنشئ جلسة، أسند نطاقات العمل، ثم ابدأ الجلسة.

## عقد CSV
### الأصناف
الأعمدة: `sku, barcode, name, category, base_unit, units, expected_qty, image_url`
- `sku` و`name` مطلوبان.
- `units`: قائمة مفصولة بـ `|` أو JSON.
- `expected_qty`: مرجع المقارنة فقط.
- `image_url`: رابط صورة قابل للوصول من جهاز المندوب. لا يُخزّن الملف في قاعدة البيانات.

### المواقع
الأعمدة: `code, name, location_type, parent_code, sort_order`
أنواع المواقع: `store, warehouse, department, aisle, shelf, bin, zone, role`.
يجب ترتيب الصفوف بحيث يسبق الأب أبناءه.

## الضوابط التقنية
- جداول التطبيق ذات بادئة `count_` وسياسات RLS مفعلة على جميعها.
- وظائف فحص العضوية الحساسة في schema غير مكشوفة `counting_private`.
- `count_record_entry` عملية RPC ذرية مع مفتاح idempotency فريد لكل حدث عميل.
- جلسة الجرد النشطة والعضوية النشطة ونطاق الإسناد تُفحص على الخادم قبل قبول العدّ.
- عمليات العدّ لا تعدّل جداول المخزون أو ERP.
- Realtime مفعّل على `count_entries`, `count_members`, `count_sessions`.
- صور المنتجات في bucket خاص `counting-product-images`، بسياسات قراءة مرتبطة بعضوية المشروع ورفع للمشرف فقط.
- التخزين دون اتصال يستخدم IndexedDB، ويعاد إرسال الأحداث بمفتاحها الأصلي لتجنب تكرار العدّ.

## ما لم يُختبر بعد
لم يُجر اختبار دخول فعلي أو إنشاء حساب مندوب أو استيراد 90 ألف صنف أو ضغط مئات الاتصالات؛ لم تُقدّم بيانات اعتماد المشرف الأول ولا بيانات اختبار. يلزم تنفيذ اختبارات E2E متعددة الأجهزة بعد إنشاء المشرف الأول، ثم اختبار حمل مرحلي قبل التشغيل الميداني. لا تعتبر النسخة معتمدة بعد لاختبار أداء 90k/مئات المستخدمين.
